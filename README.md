# API_DSM_1SEMESTE_2026

Projeto destinado a API - FATEC - Sistema de análise de crédito BCB

---

## Product Backlog (WIP)

| ID | Descrição | Estimativa | Sprint |
| :-: | :--- | :-: | :-: |
| **1** | Como cliente, desejo visualizar as estatísticas de inadimplência de regiões do país para dar oportunidade de crédito para as pessoas. | | |
| **2** | Como analista de crédito, quero visualizar as taxas regionais de inadimplência e endividamento fornecidas pelo Banco Central, para identificar o risco de calote antes de aprovar um empréstimo. | | |
| **3** | Como analista de crédito, quero visualizar o perfil socioeconômico de uma região (população, renda média e emprego do IBGE), para avaliar o potencial financeiro dos solicitantes daquela localidade. | | |
| **4** | Como analista de crédito, quero navegar pelos dados até o nível de municípios/microrregiões, para realizar análises de risco hiperlocais (visto que a realidade do bairro/cidade pode ser muito diferente do estado). | | |
| **5** | Como analista de crédito, quero visualizar gráficos comparativos de inadimplência versus renda ao longo do tempo, para identificar se uma região está melhorando ou piorando financeiramente. | | |
| **6** | Como analista de crédito, quero filtrar a visualização por período (ex: últimos 12 meses), faixa de renda e estado/município, para isolar apenas as variáveis relevantes para a minha análise atual. | | |
| **7** | Como cliente, gostaria de ter acesso a informações de PIX para avaliar rendas informais possivelmente não declaradas e assim basear melhor a escolha de concessão ou não de crédito. | | |
| **8** | Como cliente principal, gostaria de ter acesso a estatísticas que indiquem as regiões de mais vulnerabilidade social dentro de uma macro região para que possa direcionar melhor meu produto ao cliente final. | | |
| **9** | Como novo usuário, gostaria de ter acesso a uma página institucional descrevendo como os cálculos estatísticos são feitos para instruções gerais. | | |
| **10** | Como usuário, gostaria que a interface fosse intuitiva em seu funcionamento para realizar buscas por regiões. | | |
